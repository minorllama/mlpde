# Machine learning for PDEs

For everything other than PDEs, see [mlearn](https://github.com/minorllama/mlearn)

### Viscous Burgers with Cole–Hopf, Fourier RK4, a PINN, and diffusion

The project has two experiments on the periodic domain $x\in[0,2\pi)$ with viscosity $\nu=0.025$. The first solves the same initial-value problem three ways. The second learns a conditional distribution over the missing Fourier modes of a snapshot drawn from a family of initial conditions.
